## 4. Écarts restants et limites connues

- **Non validé en session réelle** :
  - l'agent flutter-architect (le TRD du démo était trivial, la session l'a rédigé elle-même) ;
  - le chemin « bloqué » d'agent-scope-guard (les agents sont restés dans leur périmètre ; testé en unitaire seulement) ;
  - le rappel légitime de checkpoint-reminder (testé en unitaire seulement).
- **Contexte des scénarios** : ils ont chargé votre configuration utilisateur, dont `plugin-dev` et `superpowers` 7.0.0, et pas seulement ce plugin.
- **Non vérifié** :
  - bash 3.2 (macOS) ;
  - le préfixe `!` face aux hooks ;
  - `stream-json` sans `--verbose` ;
  - `--max-turns`.
- **Le guard est un filet, pas une garantie.** Il ne voit pas une commande désignée par une variable, un alias git, `$'…'`, PowerShell natif, `find -delete`, `rm -r` sans `-f`, un tag poussé par son nom, `git checkout <fichier>`, ni un script lancé par fichier. Détail : `docs/SECURITY.md`.
- **Protection de `.forge/config.yaml`** : elle repose sur la règle `deny` du projet, donc sur `.claude/settings.json` installé. Le hook protect-sensitive arrive en v0.2.
- **Écart assumé avec la revue** : les étapes 13 et 14 gardent l'ordre d'ARCHITECTURE.md. Le reviewer liste les docs à mettre à jour au lieu de les signaler comme constats.
- **Ordre de développement** : create-feature part de la branche principale. Dans le scénario 5, AC-002 partait d'AC-001 non fusionné, et recover-session l'a signalé.

## 5. Commandes

Installation :

```bash
claude plugin marketplace add ~/Documents/claude-plugin/App
claude plugin install dart-multiplatform-forge@dart-multiplatform-forge --scope user
claude plugin details dart-multiplatform-forge
```

Essai sans installation : `claude --plugin-dir ~/Documents/claude-plugin/App`.

Tests :

```bash
cd ~/Documents/claude-plugin/App && bash tests/run-all.sh
```

Scénarios (consomment du quota) : `tests/scenarios/README.md`, avec `FORGE_ALLOW_QUOTA=1`.

Mise à jour (marketplace locale, lue sur place) : `/reload-plugins` dans une session ouverte, ou une nouvelle session.

Désinstallation :

```bash
claude plugin uninstall dart-multiplatform-forge@dart-multiplatform-forge --scope user
claude plugin marketplace remove dart-multiplatform-forge
```
